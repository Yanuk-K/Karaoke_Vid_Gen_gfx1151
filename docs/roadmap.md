# MVP Roadmap

1. Backend local job system and project folder lifecycle.
2. Audio upload and WAV normalization.
3. BS-RoFormer stage adapter to local UVR assets.
4. Provided lyrics + whisper.cpp fallback transcription path.
5. Word-level timing JSON with `display_start` and `sing_start`.
6. FFMPEG preview/final MP4 renderer with two-line karaoke layout.
7. Melody extraction + MIDI export.
8. Timing editor (line/word drag, nudge, text edit, countdown offset).

## Deferred

- Syllable-level editing.
- Beat-grid snap and phoneme tools.
- Multi-project batching.
- Desktop packaging (Tauri/Electron) after web MVP.
